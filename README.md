# Panna

A private diary for Windows. Everything you write is encrypted on your own PC with your master password. There is no Panna account, no Panna server, and no subscription.

- **Website:** https://panna.apnaghar.blog
- **Privacy policy:** https://panna.apnaghar.blog/privacy
- **Support:** suryashastri36@gmail.com

## Download

Get the latest installer from the [Releases page](../../releases/latest), or directly:

**[Download Panna-Setup.exe](../../releases/latest/download/Panna-Setup.exe)** — Windows 10 and 11, 64-bit.

### Installing

The installer is not code-signed yet, so Windows shows a "Windows protected your PC" screen the first time. Choose **More info**, then **Run anyway**.

Each release lists the SHA-256 of its installer, so you can check that the file you downloaded is the one published here.

## What this repository is

This repository holds the released installers only. The source code is not published here.
